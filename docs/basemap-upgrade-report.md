# 底图系统升级 · 修改前后问题清单与测试结果

> **后续简化（2026-10-17）**：应用户要求，本项目随后移除了"开始演示/六幕演示"、改革开放"播放"、缓冲区分析（功能B）、事件空间查询（功能C）与"本地增强"底图手动切换，并移除标记聚合（一律显示类别芯片图标）；建成区数据已升级为 AUE 真实数据。本报告为**底图系统升级时点的记录**，其中涉及聚合/演示/缓冲区的描述以上述简化后的现状为准。

> 本次升级聚焦"地图系统本身"——补齐地理参照、接入合规在线底图、修正比例尺/分辨率、
> 用类别语义图标替代统一菱形、完善图层管理与图例、打通卷帘双图底图。
> 技术架构不变：原生 HTML5 / CSS3 / JavaScript ES Module，无框架、无构建工具。

## 二、修改方案（How）

### 1. 底图引擎 `js/basemap.js` + `js/config.js`（新增）
- **在线底图**：天地图 `vec_w`（矢量底图）+ `cva_w`（注记），球面墨卡托 `_w` 变种，与 MapLibre 投影一致；GS(2023)336号，含合规国界/南海诸岛/九段线。密钥为浏览器端类型，存于 `config.js`。
- **离线增强底图**（本地，WGS84）：
  - `china-provinces.geojson` 省界（DataV.GeoAtlas，已核实为 WGS84）；
  - Natural Earth 10m **水系 / 干线道路 / 铁路**（裁剪至中国 bbox 并经 mapshaper 简化）；
  - `places.geojson` 95 个**合规地名**（省/地市；台湾标注"中国台湾省"，香港/澳门并列，南海诸岛单列）；
  - `nine-dash.geojson` 手绘**九段线 + 南海诸岛**（符合中国地图国标）。
- **统一装配、按需显隐**：两套基础图层都装入地图，`applyBasemapVisibility(map, mode)` 仅切换可见性，不重建地图、不丢失叠加层。背景层 `tdt-bg` 始终可见（避免切离线时非中国区域透明/黑底）。
- **可用性探测 + 快速降级**：`probeOnlineAvailable()` 请求一张瓦片，**3 秒超时**；失败即 `mode='offline'` 并弹出提示横幅（`.basemap-banner`）。
- **无在线字形依赖**：所有地名/聚合数字用 canvas 生成图片（`icon-image`），离线可用。

### 2. 比例尺/分辨率修正 `js/map.js`
- 改为 Web Mercator 地面分辨率 `156543.03392·cos(lat)/2^z`（米/像素）；
- 比例尺按 96dpi：`1cm ≈ mpp·(96/2.54)` 米；比例尺分母 `1:N = mpp/(0.0254/96)`。
- 卷帘状态栏（`analysis.js`）同步修正。

### 3. 类别语义标记 + 聚合 + 避让 + 多尺度 `js/layers.js`
- 白底圆角芯片 + 类别彩色**字形**（建筑/锚/¥/齿轮/屋舍/柱列；改革五类各配专属字形），**绝不用圆点**表示 POINT。
- 启用 MapLibre **聚合**（`cluster:true`，`clusterRadius:46`，`clusterMaxZoom:8`）：低缩放聚合、点击展开；聚合数字用金色芯片图标。
- **符号避让**：单体标记与地名标签 `icon-allow-overlap:false`（碰撞隐藏）。
- **多尺度**：`icon-size` 随缩放插值，远小近大。
- 高亮仍用**真实省级行政区轮廓**（`highlightRegion`），缓冲分析高亮**真实相交省份**（不画圆）。

### 4. 图层面板 `js/layerpanel.js`（新增）+ 接入四页
- 一体化面板：**底图切换**（在线·天地图 / 本地增强）、**图层开关**（遗产/事件/省界）、**图例**（类别图标 + 底图参照色）、**复位视图**工具。
- 接入 `history` / `reform` / `cities` / `analysis` 四页；`analysis` 的底图切换广播给卷帘双图。

### 5. 卷帘双图接入增强底图 `js/analysis.js`
- `ensureSwipeMaps` 改用 `buildOfflineStyle()` + `setupBasemap()`，在线/离线探测后双图装配同一底图；`mapA/mapB` 注册为底图广播目标，卷帘状态栏比例尺修正。

### 6. 修复关键竞态
- `setupBasemap` 在 `load` 回调内**轮询等待 `isStyleLoaded()`**（`waitMapReady`），不再直接假定就绪——否则四城页等地 `setupBasemap` 会提前 return、底图图层完全不加载。

## 三、坐标基准核实（任务 #4）

- `china-provinces.geojson` = **WGS84（EPSG:4326）**（DataV.GeoAtlas）。
- 新增 `basemap/*`（Natural Earth、places、nine-dash）均为 **WGS84**。
- 遗产点 / 改革事件坐标均为 WGS84 经纬度。
- 天地图 `_w` 为球面墨卡托，与 MapLibre 默认投影一致。
- **结论：所有点、线、面图层坐标基准统一为 WGS84。**

## 四、建成区数据（任务 #9 → 已升级为真实数据）

- **升级后**：建成区轮廓已从"模拟斑块"替换为 **Atlas of Urban Expansion（AUE, 2016）真实数据**（Landsat 解译，约 1990/2000/2014，WGS84）。界面 `#a-note`、卷帘状态栏与 `urban-index.json` 均标注真实来源与"解译近似"说明。

- 生成脚本 `scripts/gen_urban_aue.py`，源 zip 存于 `data/urban-expansion/_ghsl/`；旧模拟版备份于 `_ghsl/simulated_backup/`。

### 关键 Bug 修复记录（测试中发现）
1. `layerpanel.js` 误从 `utils.js` 导入 `REFORM_COLORS`（应在 `layers.js`）→ 模块加载失败、整页无地图。已修正导入。
2. `layers.js` `markerIconDataURL` 把 `ImageData` 传给 `canvas.toDataURL`（ImageData 无此方法）→ 图例生成抛错、面板中断。已改为先 `putImageData` 再 `toDataURL`。
3. `setupBasemap` 在 `load` 内直接假定 `isStyleLoaded()===true`，实测经 `await` 网络探测后可能瞬时为 false → 四城页底图不加载。已改为轮询等待（`waitMapReady`）。
4. 背景层 `tdt-bg` 曾被放入在线开关列表，切离线时背景消失。已固定为始终可见。
5. 卷帘状态栏 `data-sb` 属性名与主状态栏不一致，已统一。
