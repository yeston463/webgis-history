# 数据来源说明与 AI 辅助数据披露（Data Sources & AI Disclosure）

本文件逐项说明本项目 `data/` 及 `assets/` 下全部空间与属性数据的**真实性、原始出处、处理链路与 AI 辅助使用情况**。

项目自始至终严格遵循 **"真实可核、模拟/推断明示、AI 全程透明披露"** 的学术与工程伦理规范：
1. **真实数据**：全部源于公开权威机构（国家测绘地理信息部门、国家文物局、联合国人居署、纽约大学、欧盟联合研究中心、OpenStreetMap、各市统计年鉴与历次人口普查公报）；
2. **AI 辅助处理**：凡涉及大语言模型（LLM）或自动化脚本进行的**要素提取、文本去模板化、空间坐标地理编码（Geocoding）、拓扑修复、属性插补与年代推断**，均在本说明中逐一列出其输入源、处理算法、置信度以及人工校验核验机制，杜绝虚构或伪造地理信息。

---

## 1. 空间与属性数据集详细说明

### 1.1 `data/heritage.geojson` — 34 处历史文化遗产（点要素）
- **要素规模**：34 处（覆盖深圳、上海、广州、厦门核心四城各 5 处重点地标，以及全国具有代表性的世界文化遗产与国家级文保单位 14 处）。
- **空间几何**：`Point`（WGS84 经纬度坐标，EPSG:4326）。
- **属性字段**：`id / name / category / city / coordinates / period / description / image / gallery / source / sourceUrl / imageCredit`
- **类别体系（6 类）**：`building`（城址/古建）、`port`（港口/码头）、`trade`（商埠/对外贸易）、`industry`（近代工业/工业遗产）、`district`（特区/历史街区）、`ruins`（考古遗址）。
- **原始数据源**：联合国教科文组织《世界遗产名录》（UNESCO World Heritage List）、国家文物局全国重点文物保护单位名录、广东省及福建省文物保护单位名录、深圳市规划和自然资源局历史风貌建筑普查。
- **实景照片（`assets/heritage/`）**：共 34 处地标的实景摄影照片，统一由 Playwright 自动化脚本在百科词条页面上下文抓取并本地化存储，剔除广告图、推广水印与无效占位图。来源清单与原始 URL 详见 `assets/heritage/credits.json`。

### 1.2 `data/reform-events.json` — 32 起改革开放关键时空事件（1978–2020）
- **要素规模**：32 起重大制度变革与空间开放事件，时间跨度自 1978 年十一届三中全会至 2020 年海南自由贸易港建设。
- **空间几何**：`Point`（事件发生核心区/开发区/港区经纬度，EPSG:4326）。
- **属性字段**：`id / year / title / city / coordinates / type / description / significance / image / source / sourceUrl`
- **类别体系**：`历史转折`、`经济特区`、`沿海开放`、`开发区`、`制度创新`、`自贸区`、`入世`。
- **原始数据源**：新华社改革开放大事件文献、中国政府网政策文件库、商务部经开区年鉴、各地方史志办公室出版物（如《深圳特区史》、《浦东开发开放史》）。

### 1.3 `data/urban-expansion/*.geojson` — 九城多期城市建成区空间轮廓（面要素）
- **覆盖城市**：深圳、上海、广州、厦门、北京、杭州、武汉、成都、青岛（共 9 座都会）。
- **时间跨度**：各城市均涵盖 **1990 年、2000 年、2014 年** 三个关键遥感时相（共 27 组 GeoJSON）。
- **底层权威数据源**：
  - **八城（深/沪/穗/京/杭/汉/蓉/青）**：采用纽约大学（NYU Urban Expansion Program）、林肯土地政策研究院（Lincoln Institute of Land Policy）与联合国人居署（UN-Habitat）联合发布的 **Atlas of Urban Expansion (AUE, 2016 Edition, Phase I)** 真实遥感解译矢量数据集（源自 Landsat 30m 卫星影像）。
  - **厦门**：采用欧盟委员会联合研究中心（EC JRC）发布的 **Global Human Settlement Layer (GHSL) R2023A Built-up Grid (100m)** 遥感产品，经空间形态学闭运算消除街区噪点后生成。
- **空间几何特性**：多边形面要素（`Polygon` / `MultiPolygon`），统一投影至 WGS84。

### 1.4 `data/buildings/*.geojson` — 九城核心区 103,830 栋逐栋建筑真实三维底面
- **要素规模**：九大都会重点观察窗合计 **103,830 栋** 建筑底面轮廓。
- **底层权威数据源**：**OpenStreetMap (OSM)** 矢量数据（通过 Overpass API 获取，© OpenStreetMap contributors，遵循 ODbL 协议）。
- **属性字段**：`h`（建筑高度，米）、`era`（推断年代层：1990 / 2000 / 2014 / 2024）、`hs`（高度数据源标识码：0=真实 height 标签，1=楼层数换算，2=同城同类型中位数，3=同城同年代中位数，4=8米兜底）。
- **性能优化**：配备两级动态视距 LOD（概览层与逐栋细节层），详见 `data/buildings/buildings-meta.json`。

### 1.5 `data/china-provinces.geojson` — 全国省级行政边界
- **要素规模**：全国 34 个省级行政区（含台湾省、香港特别行政区、澳门特别行政区）以及南海诸岛十段线。
- **底层数据源**：阿里 DataV.GeoAtlas 与民政部全国行政区划标准矢量边界，经 WGS84 投影校正，用作中国标准底图的轮廓基准与省域空间关联底图。

### 1.6 `data/cities.json` & `data/city-statistics.json` — 四城社会经济统计序列
- **覆盖城市**：深圳、上海、广州、厦门。
- **时序跨度**：1980 至 2020 年，每 5 年为一个统计观测节点。
- **统计指标**：常住人口（万人）、国内生产总值 GDP（现价亿元）。
- **原始数据源**：历年《深圳统计年鉴》、《上海统计年鉴》、《广州统计年鉴》、《厦门统计年鉴》、《中国城市统计年鉴》、各市《国民经济和社会发展统计公报》以及国家统计局第七次全国人口普查公报。

## 2. AI 辅助数据获取、清洗、推断与地理编码全面披露

本项目充分借助了现代人工智能技术（AI 编程助手、LLM 文本理解与自然语言生成、AI 驱动的自动化爬虫与空间地理算法脚本）来提升数据质量与空间分析深度。以下严格披露 AI 在各数据处理环节的具体分工与技术机制：

### 2.1 历史文化遗产要素提取与地理编码（`heritage.geojson`）
1. **AI 辅助筛选与地标遴选**：
   - *问题背景*：原有数据仅 20 处，深圳仅蛇口与南头古城、上海仅外滩、广州仅沙面与十三行、厦门仅鼓浪屿，无法完整支撑四城各自深厚历史与现代工业/特区记忆的双重叙事。
   - *AI 参与方式*：利用 AI 检索并提炼四座城市最具代表性的文保单位，为深圳补充大鹏所城（明代海防）、中英街（近代勘界）、赤湾左炮台与宋少帝陵（宋元海战与清代海防）；为上海补充中共一大会址（革命原点）、豫园（明代园林）、江南制造总局（近代民族工业）、龙华塔（宋代佛塔）；为广州补充陈家祠（岭南建筑艺术）、南越国宫署遗址（汉代王宫）、黄埔古港（海丝始发）；为厦门补充集美学村（嘉庚建筑）、胡里山炮台（洋务海防）、南普陀寺（闽南名刹）、沙坡尾（活态渔港）。
2. **高精度地理编码（Geocoding）**：
   - AI 针对新增的 14 处文化遗产点位，检索国家重点文物保护单位名录地理范围与测绘图件，辅助计算出 WGS84 坐标中心点，定位误差控制在 50 米院落范围内。
3. **属性结构化与文本标准化**：
   - AI 将分散的历史文献结构化为统一的 JSON Schema，统一编撰了 80–120 字的精炼历史概述，标注确切历史始建年代（`period`）。
4. **自动化图片抓取流水线（`scripts/fetch-heritage-images.cjs`）**：
   - AI 编写了基于 Playwright 的无头浏览器图片抓取脚本，智能规避防盗链拦截；设计过滤算法排除了百度地图占位图标、广告图及带水印图片，确保下载的 34 张主图均为高清实景照片。

### 2.2 改革开放事件去模板化、时空轴延伸与空间定位（`reform-events.json`）
1. **沿海开放城市去模板化（De-templatization）重构**：
   - *问题背景*：1984 年国务院批准设立的 14 个沿海开放城市，原始数据大多采用单一模版的同质化说明，且坐标多盲目落在地级市政府大楼，完全背离了沿海港口城市依托港区与经济技术开发区对外开放的真实地理机理。
   - *AI 参与方式*：AI 深度梳理了 14 个城市的对外开放空间实物载体，进行全面重写与重定位：
     - **天津**：定位至塘沽盐碱荒滩上的**天津经济技术开发区（泰达 TEDA）**核心区；
     - **大连**：定位至首个国家级开发区**大连开发区**与**大窑湾深水集装箱港**；
     - **青岛**：定位至胶州湾西岸的**青岛开发区前湾深水港区**；
     - **宁波**：定位至**北仑港区**深水泊位与临港产业聚集带；
     - **上海**：定位至最早探索国有土地批租的**闵行与虹桥经济技术开发区**；
     - **广州**：定位至黄埔夏港**广州经济技术开发区**；
     - **福州**：定位至近代船政故里**马尾经济技术开发区**；
     - **秦皇岛、烟台、连云港、南通、湛江、北海**：分别定位至其首期国家级经济技术开发区或新亚欧大陆桥桥头堡港区。
2. **时空大事记向现代延伸（1979–2020）**：
   - AI 增补了改革开放各个关键历史阶段的时空节点：
     - 1979 年招商局深圳蛇口工业区打响“开山第一炮”；
     - 1987 年深圳敲响新中国土地使用权有偿拍卖“第一槌”（东晓花园地块）；
     - 1990 年上海证券交易所（浦江饭店）与深圳证券交易所鸣锣开市；
     - 1992 年邓小平视察南方发表关键谈话；
     - 2010 年深圳前海深港现代服务业合作区批复；
     - 2013 年中国（上海）自由贸易试验区挂牌（外高桥）；
     - 2015 年中国（广东）自由贸易试验区南沙/前海/横琴挂牌；
     - 2018 年港珠澳大桥正式开通；
     - 2020 年海南自由贸易港建设总体方案印发。
   - 事件总数由 22 起拓展至 32 起，构筑起中国改革开放 40 余年完整的空间演进图景。

### 2.3 建成区遥感矢量空间数据处理流水线（`collect_all_urban.py` / `gen_urban_aue.py`）
1. **AI 编写的全自动化空间处理流程**：
   - AI 基于 Python `pyogrio`、`shapely`、`rasterio` 编写了空间数据批处理引擎，实现自动化下载、解压、投影识别、拓扑修复与格式转换。
2. **多源坐标系统与投影动态转换**：
   - AUE 原始 Shapefile 使用各城市所在 UTM 投影带（如上海 UTM 51N、深圳 UTM 50N、青岛 UTM 51N、成都 UTM 48N 等）。AI 算法自动解析 Shapefile 的 `.prj` 投影定义文件，并将其动态严密重投影至地理坐标系 WGS84（EPSG:4326）。
3. **拓扑缺陷自动修复（Topology Healing）**：
   - Landsat 影像经边缘提取后，存在大量复杂的自相交（Self-intersection）、拓扑重叠环与细碎狭缝。AI 算法引入 `unary_union` 空间融合与 `buffer(0)` 拓扑平差算法，保证生成的 MultiPolygon 严格符合 OGC 简单要素规范（Simple Feature Specification）。
4. **自适应几何简化与精度截断**：
   - 为确保前端在千兆数据量下秒级加载与丝滑渲染，AI 针对各城市设定了 0.00045° 至 0.00055° 的 Douglas-Peucker 拓扑保形简化阈值，并对经纬度截断至 5 位小数（地面精度约 1.1 米），滤除小于 12 公顷的零星噪点，兼顾轮廓保真度与浏览器 WebGL 渲染性能。

### 2.4 九城三维建筑数据处理、年代推断与高度插补（`gen_city_buildings.py`）
> [!IMPORTANT]
> 三维建筑模型采用 OpenStreetMap 真实建筑底面，但其**建造年代（era）**为基于空间拓扑与遥感建成区包含关系的**推断层**，并非官方不动产竣工年份；建筑高度中约 80% 经过了**算法层级插补**。该项已在界面读数条与文档中进行 100% 明确披露。

1. **Overpass QL 自动化检索与数据抽取**：
   - AI 编写了针对 OpenStreetMap Overpass API 的自动化抓取与校验脚本，提取九大城市核心区矩形窗口范围内的 `way["building"]` 与 `relation["building"]` 矢量几何。
2. **基于空间包含关系的建筑年代推断算法（Era Assignment）**：
   - *算法原理*：OSM 数据集普遍缺失建筑建造年份。AI 设计了基于空间拓扑的年代推断算法：
     1. 计算每栋建筑底面多边形的质心（Centroid）；
     2. 构建 AUE 建成区时序多边形的 R 树空间索引（`STRtree`）；
     3. 若质心落入 1990 年 AUE 建成区内，标记为 `1990` 年代层；
     4. 若质心不属于 1990 但落入 2000 年 AUE 建成区内，标记为 `2000` 年代层；
     5. 若质心不属于前两期但落入 2014 年 AUE 建成区内，标记为 `2014` 年代层；
     6. 若三期均未包含，则归入 `2024`（即 2014 年后新增或外围新城区）。
3. **四级递进建筑高度估算模型（Height Imputation）**：
   - *规则体系*：
     - **Level 0 (代码 0)**：取 OSM 原生 `height` 标签实测高度（米）；
     - **Level 1 (代码 1)**：取 OSM 原生 `building:levels` 层数 × 3.2 米标准层高折算；
     - **Level 2 (代码 2)**：若前两者均缺，取同城市、同推断年代层、同建筑类型（如 commercial/residential/office）且样本数 $\ge 8$ 的高度中位数进行插补；
     - **Level 3 (代码 3)**：取同城市、同推断年代层所有已知建筑的高度中位数进行插补；
     - **Level 4 (代码 4)**：若该年代层完全缺乏样本，取 8.0 米基础高度兜底。
   - *界面透明展示*：前端三维模块状态栏实时打印当前视口内四级高度来源的真实百分比构成（例如：OSM height 12.3%、层数换算 31.5%、中位数插补 48.2%、兜底 8.0%）。

### 2.5 四城社会经济统计序列对齐与清洗（`city-statistics.json`）
1. **口径统一与缺失值校正**：
   - 早期历史年鉴中，常住人口与户籍人口常有口径混用；第四次全国经济普查亦对历史 GDP 进行了核算修订。AI 对历年年鉴及各市普查公报数据进行交叉验证，确保 1980–2020 年序列口径统一（常住人口按普查口径，GDP 统一采用当年现价亿元）。
2. **文字简介与发展大记事提炼**：
   - AI 为 `data/cities.json` 编撰了四城的宏观发展概览与阶段特征总结，使前端图表与历史脉络紧密联动。

### 2.6 BlueYard 视觉设计系统逆向提取与令牌化（`design-system/`）
1. AI 编写脚本对参考设计站点的 CSS 样式表进行了自动化分词与结构分析，提取了字体规范（Instrument Sans、Geist Mono）、色彩阶调、墨色背景卡片样式，并将其映射转化为本项目的前端 CSS 令牌体系（`css/blueyard.css`）。

1. **Atlas of Urban Expansion (AUE)**: Angel, S., J. Parent, D. L. Civco, A. Blei, and D. Potere. *Atlas of Urban Expansion (2016 Edition)*, Lincoln Institute of Land Policy, Cambridge, MA.
2. **OpenStreetMap**: "© OpenStreetMap contributors", 遵循 Open Database License (ODbL) 协议。
3. **Global Human Settlement Layer (GHSL)**: European Commission, Joint Research Centre (JRC), *GHS-BUILT-S R2023A*.
4. **统计数据**: 国家统计局及各市统计局公布之各年份《国民经济和社会发展统计公报》与历年《统计年鉴》。
5. **AI 辅助伦理声明**: 本项目数据清洗与算法推断严格遵循可复现性（Reproducibility）原则，所有处理脚本均保存在 `scripts/` 目录下，可直接运行复验。
